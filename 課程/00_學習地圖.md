# 雙龍門完整學習地圖

這套教材的目標，是讓你能從需求開始，自己規劃 PLC 階梯圖、在模擬器驗證，再理解 LabVIEW 如何讀寫 PLC、組成上位機。它以資料夾內現有雙龍門專案為實例，重點是三菱 FX3S 與 FX 軟元件。

## 建議學習順序

1. **先動手體驗 PLC 課程**：在 `實作環境` 目錄執行 `python .\softplc\learn.py`，播放示範並自行操作。B1/B2 是手動與復歸實務；C1～C4 是雙軸協調、循環停止、輸出仲裁、首發故障進階課。
2. **LabVIEW 課程**：雙擊 `../LabVIEW課程/開始上課.html`（不用網路）。22 堂課從零開始，一路做到自己寫出完整的雙龍門上位機 `GT_Main.vi`；每課有仿 LabVIEW 的可操作畫面、一步一步的建置步驟（含選盤路徑和接線表）和小測驗。建議 PLC 課程看懂步序和 D 暫存器之後再開始，第 12 課起要開軟 PLC。
3. **認識整個系統**：看本頁、`../專案檔案導覽.md` 和 `../實作環境/README.md`，釐清 PLC、模擬器、LabVIEW 的責任。
4. **由規格整理 I/O 與安全條件**：讀 `PLC/01_從需求到I-O表.md`，對照 `實作環境/softplc/hardware_guide.py` 和 `實作環境/docs/實機接線_FX3S-20MT.md`。
5. **把動作畫成時序與步序**：讀 `PLC/02_時序圖與步序設計.md`，定義每一步條件、輸出、回饋、逾時和取消方式。
6. **理解普通梯形圖與步進梯形圖**：在 PLC 互動課程練習掃描、自保持、邊緣、互鎖和 STL；文字原理見 `PLC/03_普通梯形圖與STL.md`。
7. **讀懂並修改本機梯形圖**：從 `實作環境/ladder/GANTRY_8Y_source.il` 和 CSV 開始，再比較擴充版。
8. **模擬驗證與 GX Works2**：讀 `PLC/05_模擬、GX_Works2與實機驗證.md`，分清模擬結果與實機待核對項目。接著讀 `PLC/06_SFC與STL_在GX_Works2操作.md`：SFC、STL、ST 的差別，以及在 GX Works2 從新建 SFC 工程、畫步與轉移、寫 TRAN、轉換、寫入到監看的完整步驟。
9. **學 LabVIEW**：照 LabVIEW 課程第 0～14 課，做出自己的通訊驅動（FX_ReadD、FX_WriteD），和軟 PLC 對話。寫不出來時打開 `../LabVIEW課程/參考答案/` 對照。
10. **自己建置、整合、除錯**：第 15～21 課組成 GT_Main.vi（雙迴圈、命令、分頁面板、心跳與重連、異常紀錄），最後照第 21 課的測試表驗收，再看實機上線注意事項。

## 每一章的學習方法

- 先用自己的話寫下「輸入條件 → PLC 判斷 → 輸出 → 完成回饋」。
- 在梯形圖監看中觀察一個掃描週期內，接點、內部繼電器、步序與輸出如何改變。
- 每次只改一個條件，先預測結果，再在模擬器驗證；結果不同就追掃描順序與保持方式。
- 任何會使輸出動作的實驗都只在軟 PLC 做。真機測試要先移除負載或隔離致動器，並由熟悉電氣安全的人員確認。

## 名詞先對齊

| 名詞 | 在本專案的意思 |
|---|---|
| PLC | 執行階梯圖、讀取實體輸入並控制輸出的控制器。 |
| 軟 PLC | Python 程式模擬 PLC 掃描和機構，不是實體 FX3S。 |
| LabVIEW / HMI | 上位機畫面；送命令、讀狀態、顯示與記錄。正常設計不讓 HMI 直接驅動 Y 輸出。 |
| 梯形圖來源 IL | 本專案用來產生梯形圖 CSV/文字表的指令來源，不等同 GX Works2 原生專案檔。 |
| STL | 三菱步進梯形圖指令，使用 S 步序元件與 STL/RET 區段；不是所有品牌都用相同語法。 |
| SFC | 順序功能圖：用「步」和「轉移」畫流程。FX 的 SFC 下載後就是 STL 指令。 |
| I/O | X 通常代表輸入，Y 通常代表輸出；三菱 FX 的 X/Y 位址採八進位編號。 |
