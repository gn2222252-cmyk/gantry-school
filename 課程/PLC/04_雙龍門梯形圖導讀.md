# 04｜讀懂雙龍門梯形圖與不擴充版取捨

## 先找對版本

- `實作環境/ladder/GANTRY_8Y_source.il`：不擴充版來源，目標是 8 點 Y 輸出；配套 `GANTRY_8Y.csv`。
- `實作環境/ladder/GANTRY_PLC_source.il`：擴充輸出版來源；配套 `GANTRY_PLC.csv`，含擴充輸出抽象點。
- `實作環境/softplc/softplc.py --no-board --ladder`：選擇不擴充版模擬。

不要把兩份 CSV、IL 和 LabVIEW VI 交叉混用。啟動模擬器時看它印出的實際 CSV 路徑，確認是 `GANTRY_8Y.csv`。

## 讀程式的順序

1. 看 I/O 定義與註解 CSV，先知道符號代表的機構。
2. 看 `GANTRY_8Y_source.il` 的標題和程式段標記，記下 P 段用途。
3. 對每一段寫下「條件、線圈/指令、保持方式、復位方式」。
4. 在監看視窗選同一段，觀察條件變化時哪一列導通、哪些 M/S/D/Y 改變。
5. 追命令從 HMI 寫入的 M 位元，到 PLC 條件，再到 Y 輸出和回饋位元，最後回到 HMI 顯示。

源碼註解和 `ladder/GANTRY_PLC_說明.md` 可作為導讀，但舊說明曾以 FX3U/擴充版為背景。點位與程式行為以本資料夾中的 `GANTRY_8Y_source.il`、CSV 和 `hardware_guide.py` 為準；實際端子仍以 FX3S 硬體手冊核實。

## 不擴充版的設計代價

FX3S-20MT 的本體輸出點數有限。本模擬方案把左右氣缸設計成同組輸出，並使用 8Y 版配置；這代表左右氣缸不能各自獨立命令，配線和機構動作也必須符合這個限制。若工藝要求左右獨立升降或更多獨立閥線圈，8Y 版本可能無法滿足，需重新做 I/O 配置並評估擴充，不可單靠改 LabVIEW 解決。

「能在軟 PLC 跑」只證明軟體程式在模擬環境可執行，不證明 CPU 端子容量、輸出電流、共用端接法、氣閥負載、馬達驅動或安全迴路合格。

## 手動模式要學的重點

手動模式是逐項測試機構和 I/O 的維修/調試功能，不等於解除互鎖。每個按鈕必須明確對應命令 M、方向、限位條件和停止行為。上升/下降、前進/後退不得同時有效；按住點動按鈕才動，放開即停止，是常見的點動規則，但本機實際行為要以 IL 中手動網路確認。模擬手動控制不能直接照搬成實機操作規程。

## 練習

用一頁紙畫出「HMI 手動按鈕 → D/M 命令 → PLC 互鎖/限位 → Y 輸出 → 模擬感測器 → 狀態回傳」。在每個箭頭旁寫出使用的位址與程式檔位置。
