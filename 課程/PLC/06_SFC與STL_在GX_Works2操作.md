# 06｜SFC 和 STL 的差別，以及在 GX Works2 寫 SFC

> 先讀 `03_普通梯形圖與STL.md`。本章用 FX3S 和 GX Works2（繁體中文介面）說明。選單名稱在不同版本可能略有差異，看不到時對照括號裡的英文名稱，或把滑鼠停在工具列圖示上看提示。

## 1. 三種寫法：普通梯形圖、STL、SFC

三菱 FX 寫步序（一步一步動作）的程式，常見三種做法：

| | 普通梯形圖（用 M 做步序） | STL 步進梯形圖 | SFC 順序功能圖 |
|---|---|---|---|
| 長什麼樣子 | 一般接點、線圈，用 M 位元代表「現在在第幾步」 | 還是梯形圖，但用 `STL S20` 把程式切成一段一段，每段就是一步 | 一張流程圖：方框是「步」、橫線是「轉移條件」，點進去才看到梯形圖 |
| 步序元件 | M（自己管理互斥） | S（狀態繼電器） | S（狀態繼電器） |
| 換步方式 | 自己寫 SET/RST，前一步要自己清掉 | `SET S21`：自動把目前的步關掉 | 畫一條轉移，條件寫在轉移裡，最後接 `TRAN` |
| 看出「現在在哪一步」 | 難，要追 M 位元 | 中等，看哪個 STL 接點亮 | 最容易，監看時目前的步會反白 |
| 分支（選擇、並行） | 自己寫 | 可以寫，但不好讀 | 直接畫選擇分支、並行分支 |
| 在 GX Works2 用什麼工程 | 梯形圖工程 | 梯形圖工程 | **SFC 工程**（程式語言選 SFC） |
| 下載到 PLC 後 | 一般指令 | `STL` / `RET` 指令 | **也是 `STL` / `RET` 指令**（FX 的 SFC 本質上就是 STL 的圖形版） |

重點：

- **SFC 和 STL 是同一套機制的兩種畫法。** FX 的 SFC 下載到 PLC 後就是 STL 指令；用梯形圖工程從 PLC 讀出來，會看到 `STL Sxx`、`SET Syy`、`RET`。
- **用 STL 時，同一個 Y 可以在不同的步各寫一次 `OUT`**（不算雙線圈），因為同一時間只有一個步的區段在執行。普通梯形圖這樣寫就會出問題。
- **在步裡用 `OUT` 的輸出，離開這一步就自動 OFF**；要跨步保持的輸出要用 `SET`，之後在別的步 `RST`。
- **SFC 和 STL 都不會自動幫你做安全互鎖**，急停、極限、氣壓不足要另外寫在普通梯形圖區塊（每圈都會執行的地方）。

### 順便分清楚：ST 不是 STL

| 名稱 | 意思 |
|---|---|
| **STL**（Step Ladder） | 三菱 FX 的步進梯形圖指令，本章的主角。 |
| **ST**（Structured Text） | 結構化文字，像 Pascal / C 的文字語言（`IF X0 THEN Y0 := TRUE; END_IF;`），屬於 IEC 61131-3。GX Works2 的 FX 簡單工程不能用 ST，要用「結構化工程」才有，FX3S 一般不用它寫步序。 |
| **IL**（Instruction List） | 指令表（`LD X0`、`OUT Y0`），本專案的 `GANTRY_8Y_source.il` 就是這種。 |

## 2. 看懂你畫面上的 SFC

GX Works2 的 FX SFC 工程，程式由「區塊（Block）」組成：

| 區塊 | 種類 | 用途 |
|---|---|---|
| `000:Block` | **梯形圖區塊**（外部程式） | 每圈都執行。放「啟動初始步」（例如 `M8002` → `SET S0`）、急停、手動、告警等不屬於某一步的程式。 |
| `001:Block1` | **SFC 區塊**（步進程式） | 流程圖本身。 |

以上課截圖的 SFC 為例：

```
 ┌═┐ 0      ← 初始步 S0（雙框）
  ┼  0      ← 轉移條件 0：X000 → TRAN
 ┌─┐ 10     ← 步 S10（監看時反白 = 目前正在這一步）
  ┼  1      ← 轉移條件 1
 ┌─┐ 11     ← 步 S11
  ┼  2      ← 轉移條件 2
  ↳ 0       ← 跳躍（Jump）回 S0
```

- 左邊數字欄 1、2、3…是格子行號，**框旁邊的數字才是步號（S 編號）或轉移編號**。
- 右邊視窗「移轉編號0」就是點兩下轉移條件 0 打開的內部梯形圖：`X000` 接點 → `[TRAN]`。意思是 X000 ON 就從 S0 換到 S10。
- 步和轉移一定要**一個步、一個轉移交替**排列。

## 3. 從零建立 SFC 工程（FX3S）

1. **新建工程**：`工程(P)` ▸ `新建工程`（New Project）
   - 系列：**FXCPU**
   - 機種：**FX3S**
   - 工程類型：**簡單工程**（Simple Project）
   - 程式語言：**SFC**
   - 按確定。若 GX Works2 要你選第 0 號區塊的類型，選**梯形圖區塊**；若直接建好了，在左邊 `MAIN` 底下確認 `000:Block` 是梯形圖區塊（圖示和 SFC 區塊不同），不是的話刪掉重建。
2. **寫區塊 0（梯形圖區塊）**：打開 `000:Block`，至少寫一行
   ```
   M8002 ──────────────[SET S0]      ← PLC 上電/RUN 第一圈啟動初始步
   ```
   沒有這行，SFC 一個步都不會亮，整個流程不會動。這是新手最常犯的錯。
3. **新增 SFC 區塊**：在左邊導航視窗 `程式` ▸ `MAIN` 上按右鍵 ▸ `新建資料`（Add New Data），區塊類型選 **SFC 區塊**，取個標題（例如「步進程式」），就會出現 `001:Block1`。
4. **畫流程圖**：打開 `001:Block1`，畫面上第一個步（初始步 S0）已經在了。用工具列的 SFC 按鈕（滑鼠停上去會顯示名稱和快速鍵）：
   | 工具列按鈕 | 用途 |
   |---|---|
   | 步（STEP） | 插入一個步，輸入步號，例如 `20` |
   | 轉移（TR） | 插入轉移條件 |
   | 選擇分支／選擇合併 | 依條件走其中一條路（例如良品走 A、不良品走 B） |
   | 並行分支／並行合併 | 兩條路同時跑（例如兩軸同時移動），全部完成才合併 |
   | 跳躍（JUMP） | 跳到指定步號，例如回到 `0` 形成循環 |
   | 結束步（END） | 區塊結束 |

   做法：游標移到要放的格子 → 按工具列按鈕（或快速鍵）→ 輸入編號 → 確定。
5. **寫每一步的動作**：在步上**點兩下**，打開這一步的內部梯形圖。例如 S20 要讓 Z 軸下降：
   ```
   ───────────────────────────(Y002)     ← 在 S20 期間 Y002 ON，離開 S20 自動 OFF
   ───────────────────(T0 K30)          ← 逾時計時
   ```
   步的內部梯形圖不需要再寫 `STL`，GX Works2 會自動加。
6. **寫每一個轉移條件**：在轉移上**點兩下**，寫條件，最後一定接 `TRAN`：
   ```
   X003 ──────────────[TRAN]             ← 下降到位 X003 ON 才換下一步
   ```
   在梯形圖輸入框直接打 `TRAN` 按 Enter 即可。
7. **轉換（編譯）**：`轉換/編譯(C)` ▸ `轉換（全部程式）`（Rebuild All）。**每個步和每個轉移都要轉換過**，沒轉換的部分是灰色的，下載會失敗。錯誤會顯示在下方「輸出」視窗的「轉換SFC圖」頁籤，點兩下錯誤跳到位置。
8. **寫入 PLC**：先確認連線（`連接目標` ▸ Serial USB），PLC 切到 STOP，`線上(O)` ▸ `PLC寫入`（Write to PLC），勾**參數 + 程式**，執行。寫完把 PLC 切回 RUN。
9. **監看**：`線上(O)` ▸ `監看` ▸ `監看模式`（F3）。SFC 圖裡**目前有效的步會反白（藍色）**；點兩下步或轉移，可以同時監看裡面的梯形圖（就像截圖右邊那樣）。

## 4. 常見錯誤

| 現象 | 原因／處理 |
|---|---|
| SFC 一個步都不亮 | 區塊 0 沒有用 `M8002`（或啟動按鈕）去 `SET S0` |
| 轉換時說轉移沒有 TRAN | 轉移內部梯形圖最後要接 `TRAN`，不是 `OUT` |
| 灰色的步／轉移，寫入失敗 | 沒有轉換，用「轉換（全部程式）」 |
| 換步後輸出還 ON | 那個輸出是用 `SET` 寫的，`SET` 不會隨步結束而 OFF，要在別的步 `RST` |
| 兩個步都亮 | 用了並行分支，或在步裡用 `SET` 啟動了另一個步卻沒有離開；檢查分支種類 |
| 急停按了沒反應 | 急停寫在某個步裡面，那個步不在執行時就不會被掃描。安全條件要寫在**梯形圖區塊**，例如用 `ZRST S0 S255` 把所有步清掉再停輸出 |
| 計時器沒復歸 | 在步裡用 `OUT T0` 的計時器，離開步會自動復歸；相鄰兩步不要用同一個計時器 |
| 監看看不到動作 | 確認已切到監看模式（F3），而且 PLC 在 RUN |

## 5. 和本專案的關係

- 本專案的 `GANTRY_8Y_source.il` 使用的是 **STL 指令**（搜尋 `STL`、`SET S`、`RET`）。把它畫成 SFC 圖，就是同一個流程的圖形版。
- 每一個 `STL Sxx` 區段 = SFC 的一個步；區段裡 `SET Syy` 前面的條件 = SFC 的轉移條件。
- 不在任何 STL 區段裡的網路（急停、手動、HMI 心跳 D240/D241、告警）= SFC 工程的**梯形圖區塊**。
- LabVIEW 只讀寫 D 暫存器和 M 指令位元，**PLC 用 STL 還是 SFC 寫，LabVIEW 端完全不用改**。

## 6. 練習

1. 照第 3 節建立一個 FX3S SFC 工程，畫出：S0 →（X000 啟動）→ S20 Y000 ON →（T0 K20）→ S21 Y001 ON →（X001）→ 跳回 S0。
2. 先**離線**轉換成功，再用「模擬」（`除錯(B)` ▸ `模擬開始/停止`，需有安裝 GX Simulator2）或接實機監看，觀察反白的步怎麼移動。
3. 把同一個流程改用梯形圖工程，用 `STL`、`SET`、`RET` 手寫一次，比較兩者的可讀性。
4. 加一個選擇分支：S21 時若 X002 ON 走 S30（不良品），否則走 S22（良品），最後合併。
5. 在梯形圖區塊加急停：`X010`（急停）→ `ZRST S0 S255`，確認任何步執行中按下都會全部停止。

## 7. 為什麼 GX Works2 的畫面和課本上的 SFC 圖長得不一樣

課本上的 SFC 圖是「**設計圖**」：要讓人一眼看懂整個流程，所以步的動作、轉移條件全部寫在圖上。
GX Works2 的 SFC 畫面是「**編輯器**」：只畫骨架（步號、轉移編號、連線），動作和條件藏在每個步、每個轉移的「內部梯形圖」裡，**點兩下才看得到**。兩者是同一個程式的不同呈現方式。

### 同一個程式，兩種畫法

上課截圖的程式，畫成課本的樣子大約是：

```
課本畫法（設計圖）                      GX Works2 畫法（編輯器）

   M8002                                  （M8002 寫在另一個區塊 000:Block）
 ──┼──                                     
 ╔═════╗                                  1  ▣ 0        ← 雙框＝初始步
 ║ S0  ║                                  2  ┼ 0        ← 只顯示「轉移編號 0」
 ╚══╤══╝                                  3  │
  ──┼── X000   ← 條件直接寫在旁邊          4  ■ 10       ← 藍色實心＝目前執行中
 ┌──┴──┐                                  5  ┼ 1
 │ S10 ├──( Y000 )  ← 動作寫在右邊         6  │
 └──┬──┘                                  7  □ 11
  ──┼── X001                              8  ┼ 2
 ┌──┴──┐                                  9  │
 │ S11 ├──( Y001 )                       10  ↳ 0        ← 跳躍到步 0
 └──┬──┘
  ──┼── X002
    └──→ 回到 S0（畫一條線拉回去）
```

（右半邊條件和動作的元件只是舉例；你程式裡的實際內容要點兩下各步、各轉移才看得到。）

### 逐項對照

| 你看到的 | 課本通常畫成 | 原因／意思 |
|---|---|---|
| 步旁邊只有數字 `0`、`10`、`11` | 方框裡寫 `S0`、`S20`、`S21` | GX Works2 省略「S」，數字就是 S 編號。 |
| 步旁邊**沒有動作** | 步的右邊畫動作框（`Y000` 等） | 動作寫在步的內部梯形圖。點兩下步才會開。 |
| 轉移是一個小「┼」加編號 `0`、`1`、`2` | 一條短橫線，旁邊寫條件（`X000`） | 轉移編號只是流水號，**不是 X000 的 0**。條件在內部梯形圖裡，點兩下才會開（截圖右邊「移轉編號0」視窗就是轉移 0 的內容：`X000 ─[TRAN]`）。 |
| 轉移的梯形圖最後是 `[TRAN]` | 只寫接點 | `TRAN` 是 GX Works2 規定的「轉移成立」結尾，課本設計圖不用畫。 |
| 最上面沒有 `M8002` | 初始步上方畫 `M8002` 或啟動條件 | GX Works2 把啟動初始步寫在另一個**梯形圖區塊**（`000:Block`）。你的 `000:Block` 顯示「3步序」，正好是 `LD M8002`（1 步）＋ `SET S0`（2 步）。 |
| 最下面是 `↳ 0` | 從最後一步拉一條線回到最上面 | GX Works2 不畫回頭的長線，改用「跳躍」符號加目標步號，`↳ 0` 就是跳回 S0。 |
| 步 0 是雙框，中間有一個點 | 雙框（初始步） | 雙框代表初始步；框裡的點是 GX 標記「這一步是某個跳躍的目的地」（從第 10 行的 `↳ 0` 跳過來）。 |
| 步 10 是**藍色實心** | 課本是靜態的圖，沒有顏色 | 你在**監看模式**（標題寫「監視 執行中」）：藍色實心＝這一步目前有效（正在執行）。步 11 是空心＝沒在執行。 |
| 轉移編號 0 外面有一個方框 | 沒有 | 那是游標（目前選取的格子），所以右邊打開的是轉移 0 的內容。 |
| 右邊 `X000` 接點是藍色實心 | 沒有 | 監看時接點 ON 會填滿藍色，表示 X000 現在是 ON。 |
| 左邊有 1～23 行號、上方有 1～7 欄號 | 沒有 | 編輯器的格子座標。欄 2～7 用來畫選擇分支、並行分支。行號**不是步號**。 |
| 第 3、6、9 行只有直線 | 沒有 | 格子之間的連線，沒有程式意義，不影響執行。 |
| 標題寫「50步序」「1步序」 | 沒有 | 這裡的「步序」是**程式記憶體的大小**（指令佔幾個 step），**不是 SFC 有幾個步**。整個 SFC 區塊轉成 STL 指令後佔 50 個程式步，轉移 0 佔 1 個程式步。 |
| 標題寫「唯讀」 | 沒有 | 監看模式下不能修改。要改程式，先退出監看，切到寫入模式（`編輯` ▸ `寫入模式`，或 F2）。 |
| 步號用 `10`、`11` | 課本多半從 `S20` 開始 | 三菱慣例：S0～S9 初始步，S10～S19 保留給 `IST` 指令的原點回歸，一般步從 S20 起。沒用 `IST` 時用 S10 也能正常動作，但建議照慣例改成 S20、S21，看別人的程式或課本才不會混亂。 |

### 怎麼讓 GX Works2 的畫面接近課本

- **點兩下**步或轉移，看它的內部梯形圖；監看時可以把 SFC 圖和內部梯形圖並排（就像截圖左右兩個視窗）。
- 在 `檢視(V)` 選單找「註解顯示」（Comment），先在「全域元件註解」幫 X000、Y000、S20 寫中文註解，SFC 圖和梯形圖上就會顯示名稱。
- 想要一張完整的「課本式」流程圖：照第 7 節左半邊的格式，自己在紙上或文件裡畫，作為設計和交接文件；GX Works2 裡的 SFC 則是實際下載的程式。

> 安全提醒：在實機測試前，先移除負載或隔離致動器。任何會讓輸出動作的試驗，先在模擬器（GX Simulator2 或本專案軟 PLC）做。FX3S 的 S 元件範圍、停電保持範圍和特殊繼電器，以三菱 FX3S 手冊為準。
