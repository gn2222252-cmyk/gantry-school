# 03｜普通梯形圖、掃描週期與三菱 STL

## PLC 一圈在做什麼

典型循環可先理解成：讀取輸入映像 → 由上到下執行程式 → 更新輸出映像 → 重複。接點不是像實體導線那樣連續流動；程式中的條件在每次掃描時計算。某個線圈在上方網路被改變，下面網路可能在同一掃描讀到新值；上方尚未執行的網路不能預知未來。

這正是按鈕脈衝、`PLS/PLF`、計數器和同一個 M 多處使用時需要看掃描順序的原因。接點 `X0` 代表讀到的輸入狀態；常開/常閉符號代表邏輯判斷，並不直接等於現場按鈕的 NO/NC 端子種類。

## 普通梯形圖

- 串聯：條件全部成立（AND）。並聯：分支任一成立（OR）。
- 常閉邏輯接點：該位元為 OFF 時導通（NOT）。
- `OUT M0`：每圈依條件更新；條件消失，線圈通常回 OFF。
- `SET M0` / `RST M0`：置位/復位保持位元；需明確寫復位路徑。
- `PLS M0` / `PLF M0`：在輸入上升沿/下降沿產生一掃描脈衝（實際可用元件範圍依 FX3S 手冊/程式語法確認）。
- `T0 K30`：使用計時器 T0，K 是設定值；計時基底依該 PLC 的計時器型別而定，不能只憑 K30 就說是 30 秒。
- `INC D1`：資料暫存器 D1 加一；執行條件若每圈成立，就可能每掃描加一，通常要先做單次脈衝或用一次完成旗標。
- `M8013` 等特殊繼電器：特殊用途元件的作用與時基需按 FX3S 對應手冊確認，不能因為模擬器有同名位元就假定實機完全相同。

## 步進梯形圖 STL

STL 使用步序元件 `S`。掃描到有效的 `STL S0` 後，執行該步區段；轉移條件成立時用 `SET S20` 等方式切換步序。`RET` 結束 STL 區域。需要確認實際 STL 語法和初始步設定可在 `實作環境/ladder/GANTRY_8Y_source.il` 搜尋 `STL`、`SET S`、`RET`。

注意：`STL S0` 不是把 S0 設成 ON 的線圈，而是標示該步的區段入口；進入 S20 是由程式中的步序轉移條件造成。若同一掃描先後清除/置位步序，必須依 PLC 指令執行規則和程式順序分析。不可只看畫面上某線圈顏色猜測。

## 將普通梯形圖整理為步進程式

1. 先列出原本 M 步序每個狀態的動作和轉移條件。
2. 把互斥狀態映射成獨立 S 步序，保留非步序的告警、手動、互鎖網路。
3. 每個普通網路只搬到對應的 STL 區段；不要把全程共用安全條件誤放到單一步驟。
4. 確保每一個可達狀態都有明確下一步、停止處理和復歸路徑。
5. 在模擬器逐步驗證每個轉移；確認沒有兩個互斥步序同時有效，也沒有無法離開的步序。

## 練習

在互動課程中逐個觀察 A4（SET/RST、PLS/PLF）、A6（特殊繼電器）、A7（STL 步序）和 A8（逾時）。每次記錄：「本圈輸入、執行到的網路、位元前值/後值、線圈結果、下一圈差異」。若互動課程的文字與 PLC 手冊定義不一致，以 FX3S 對應手冊為準，並在 `專案檔案導覽.md` 的待核對項目記錄。
