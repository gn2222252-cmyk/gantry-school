# FX3U-485-BD 通訊參數

> **目前不適用。** 現在用編程協定走內建 RS-422，見 `docs\通訊協定.md`，PLC 系統(2) 不要勾選。以下是舊版 FX3U 的設定。

路徑：GX Works2 → **Parameter → PLC Parameter → PLC System(2)**。

| 項目 | 設定 |
| --- | --- |
| Channel | CH1 |
| 勾選 Operate Communication Setting | 是 |
| Protocol | Dedicated Protocol（計算機連結） |
| Data Length | 7 bit |
| Parity | Even |
| Stop Bit | 1 bit |
| Transmission Speed | 9600 bps |
| Sum Check | 勾選 |
| Control Mode | Form 1（格式 1） |
| Station Number | 00H |
| Time Out Judge Time | 1（× 10 ms） |

寫入後**斷電再上電**才生效。

## 接線

| 從 | 接到 |
| --- | --- |
| USB-RS485 的 A+ | 485-BD 的 RDA 與 SDA（短接） |
| USB-RS485 的 B- | 485-BD 的 RDB 與 SDB（短接） |
| USB-RS485 的 GND | 485-BD 的 SG |

兩線式半雙工要把 RDA／SDA、RDB／SDB 分別短接。實際端子名稱以 485-BD 手冊為準，通訊不上時先對調 A、B。

## LabVIEW 端

Main.vi 底部 **PLC Transport** 選 `COM`，**COM Port** 選 USB-RS485 的埠。程式固定 9600、7 位、偶校驗、1 停止位。

## 實機第一步

先不要啟動機台。開 `Main.vi` 選好 COM 按 Run，看 **PLC Connected** 和 **PLC Alive** 亮、IO Monitor 頁的燈跟著現場開關變，就代表通訊正常。`FX_Test.vi` 固定走 TCP，只給模擬器用。
