# GANTRY_PLC 梯形圖說明

目標 PLC：**FX3U-32MR/ES**（X0～X17、Y0～Y17）。程式分 P1～P10 十段，步數見 `GANTRY_PLC.txt` 最後一行。

## 檔案

| 檔案 | 用途 |
| --- | --- |
| `GANTRY_PLC_source.il` | 原始檔，要改梯形圖就改這份 |
| `devices.py` | 軟元件名稱表。改線只改這裡的註解和程式裡的位址 |
| `build_ladder.py` | 產生下面四份，並檢查步數、指令、有沒有元件漏註解 |
| `GANTRY_PLC.txt` | 指令表，依 P1～P10 分段，含步序編號與中文註解。**匯入失敗時照這份手打** |
| `GANTRY_PLC.csv` | GX Works2 指令表 CSV，軟體 PLC 也讀這份 |
| `GANTRY_comments_zh.csv`、`GANTRY_comments_en.csv` | 軟元件註解。電腦系統不是中文時用 en，中文可能變亂碼 |
| `通訊參數設定.md` | PLC 參數怎麼設 |

修改步驟：改 `GANTRY_PLC_source.il` → 執行下面兩行。

```bash
python build_ladder.py
```

```bash
python ..\softplc\tests\test_ladder.py
```

## 匯入 GX Works2

1. 新建工程：**Project Type = Simple Project**、**PLC Series = FXCPU**、**PLC Type = FX3U/FX3UC**、**Language = Ladder**。
2. 程式：用 GX Works2 的 CSV 讀入功能選 `GANTRY_PLC.csv`（選單名稱我沒有在真的軟體上確認）。讀不進去就在指令表模式照 `GANTRY_PLC.txt` 手打，步序編號可以對照。
3. 註解：開 **Global Device Comment**，用 CSV 讀入選註解檔。讀不進去就先跳過，不影響動作。
4. 設參數：見 `通訊參數設定.md`。
5. **Convert → 寫入 PLC → 斷電重開**（通訊參數重開才生效）。

**CSV 匯入還沒在真的 GX Works2 驗證過。** 程式 CSV 的格式照 13_PLC 的範本，標頭 PLC 型號改成 FX3U；註解 CSV 是依一般欄位格式做的。

## 各段做什麼

| 段 | 內容 |
| --- | --- |
| P1 初始化 | 清 D200～D253（FX3U 預設 D200～D511 停電保持，不清的話舊異常碼會留著）；SET S0；D100～D102 為 0 時填預設值 |
| P2 輸入整理 | 按鈕 OR HMI 命令，轉成一掃描脈衝 M6～M9；HMI 脈衝命令取完邊緣後 RST |
| P3 模式與安全 | 急停、手動判斷；原點與自動的啟動條件；異常復歸；異常中清步序；循環停止 |
| P4 原點 | S0 待機，S10～S13 原點復歸 |
| P5 右龍門 | S20～S28，前 → 後 |
| P6 左龍門 | S40～S48，後 → 前。之後 RET，再判斷「兩邊都在等料且循環停止中」就結束自動 |
| P7 手動 | M5 手動有效條件；不有效時 ZRST M110～M130；命令轉到 M70～M85；手動移動過就清原點完成 |
| P8 逾時 | 步序不變才累計；碼 10／11／20／21／30；D240 心跳監視 T30 |
| P9 輸出 | **唯一驅動 Y 的地方**：自動 OR 手動，再加互鎖 |
| P10 燈號與狀態 | 閃爍、Y13～Y15、M200～M205、D200～D241 |

## 架構書沒寫清楚、我做的決定

| 項目 | 做法 | 為什麼 |
| --- | --- | --- |
| 「異常中所有輸出 OFF」和「紅燈閃、蜂鳴器響」衝突 | 只關機構輸出 Y0～Y12，Y13～Y15 照常 | 否則異常時看不到警示 |
| 3.3 節急停接點串「輸出 COM」 | **只能串 COM1～COM3**，COM4（紅燈、蜂鳴器）不可串 | 同上，接線時要注意 |
| 逾時寫「停止該龍門」，互鎖寫「所有輸出 OFF」 | 兩座龍門和輸送帶全停 | 取較安全的做法，復歸後一定要原點 |
| 「遙控模式」沒定義 | 指手動模式（X16 OFF）。此時 HMI 是唯一操作站，斷線報 40 | 自動模式現場還有按鈕，斷線不停機 |
| HMI 正常關閉 | Main.vi 結束時寫 D240 = 0，PLC 視為沒有 HMI | 正常關程式不該留下異常 |
| 綠燈 | 運轉中或已原點常亮，原點復歸中閃 | 4.3 節與測試 2 要求原點完成綠燈亮 |
| 紅燈 | 非運轉就亮，所以已原點待機時紅綠都亮 | 3.2 節「停止時亮」與測試 1、5 |
| 現場沒有原點按鈕 | 沒異常且未原點時，按復歸 X17 就開始原點。所以異常後按兩次：第一次清異常，第二次回原點 | 現場要能獨立操作 |
| 運轉中把模式切手動 | 視同循環停止，這一趟做完才允許手動 | 避免自動與手動同時動 |
| 手動動過機構 | 清除原點完成，要重新原點 | 否則起動時位置不明 |
| 手動點動橫軸（架構書沒有這條） | 碰到該方向的定位感測器就停，例如往前碰到 X0、X2 | 否則會衝過感測器撞極限開關，Home 也找不回來。自動流程不受影響 |
| D212 總循環數 | 取 D210、D211 較小者 | 一個物件兩邊都搬過才算一圈 |
| 新增元件 | M5～M9、M14～M18、M22、M23、T21、D250～D253 | 架構書表裡沒有，放在未用位址 |

## 要注意

- **急停會放掉工件。** 吸盤是單動常閉閥，斷電就失去真空，工件會掉下去。架構書如此規定；如果工件掉落有風險，要改成斷電保持的閥或加機械擋。
- **目前機型是 FX3S-20MT/ES＋FX3G-2EYT-BD。** 點位差異見 `docs\實機接線_FX3S-20MT.md`；本文件其餘 X14～X17、Y10～Y15 的敘述是舊版架構書內容。
- **FX3S 的 S0～S127、D128～D255 斷電保持。** 程式開機用 M8002 清除 S0～S59 和 D200～D253，所以兩種機型都從 S0 開始。
- **D100～D103 斷電不保持。** FX3U 預設只有 D200 以上保持，所以重新上電回到預設值，要從參數頁再寫一次。
- **C0、C1 上限 32767**，到了就停在 32767，要用 Clear Counts 清除。
- **輸出是繼電器。** 手動連續點動時注意壽命，這個程式沒有限制頻率。
