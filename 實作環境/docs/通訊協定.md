# 通訊協定：FX 編程協定

LabVIEW 和 PLC 之間用 **FX 編程協定**，走 FX3S 內建的 RS-422 埠，不用通訊板。程式由 `13_PLC` 的驅動複製過來修改。

舊版計算機連結的驅動和文件在 `backup_FX3U版\driver_computer_link\`。

**還沒有在實機驗證。** `0`、`1` 命令和 D 位址 `1000h` 是 FX 舊款機型的格式，要接上 FX3S 才能確認。

## 接線

| 路徑 | 接線 | Main.vi 的 PLC Transport |
| --- | --- | --- |
| 模擬器 | TCP 127.0.0.1:5551 | TCP (simulator) |
| **實機（主要）** | USB-SC09-FX 或 FX-USB-AW 接 PLC 圓形 8 pin 埠 | RS-422 (COM) |
| 內建 USB | USB A 轉 Mini-B | USB (COM)，只有裝置管理員出現 COM 埠時才能用 |

手冊裡 GX Works2 接內建 USB 時選的是 **[USB]**，不是 COM 埠，所以內建 USB 很可能不會出現 COM 埠。LabVIEW 連不上時用 RS-422。

GX Works2 和 LabVIEW 不能同時佔用同一個埠。GX2 用內建 USB，LabVIEW 用 RS-422，就可以同時連線。

## 序列參數

9600 bps、7 資料位、偶校驗、1 停止位。程式固定這組值。PLC 的 **PLC 系統(2)** 不要勾選。

## 封包

| 動作 | 送出 | 回應 |
| --- | --- | --- |
| 確認連線 | `ENQ` (05h) | `ACK` (06h) |
| 讀 | `STX '0' AAAA NN ETX SS` | `STX 資料 ETX SS` |
| 寫 | `STX '1' AAAA NN 資料 ETX SS` | `ACK` |
| 錯誤 | | `NAK` (15h) |

- `AAAA`：位址，4 個十六進位字元。D0 在 `1000h`，每個 D 兩個位元組。
- `NN`：位元組數，2 個十六進位字元。程式每次最多 64 位元組。
- `資料`：每個位元組 2 個十六進位字元，**低位元組在前**。
- `SS`：STX 之後到 ETX（含）的總和，取低 8 位，2 個十六進位字元。

範例：讀 D100 一個字

```text
02 30 31 30 43 38 30 32 03 37 31
STX '0' '10C8' '02' ETX '71'
```

位址：`1000h + 100 × 2 = 10C8h`。

## 只用 D

編程協定寫位元的位址各機型不同，所以 LabVIEW 只讀寫 D，PLC 再轉成 M。

### LabVIEW → PLC

| D | 內容 |
| --- | --- |
| D100～D103 | 吸附時間、釋放時間、動作逾時、目標次數 |
| D106 | 脈衝命令：位元 0～4 ＝ M100 啟動、M101 停止、M102 原點、M103 復歸、M104 計數清除。PLC 收到就清成 0 |
| D107 | 手動命令：位元 0～15 ＝ M110～M125。按住為 1，放開為 0。手動無效時 PLC 清成 0 |
| D240 | HMI 心跳，每秒加 1，0 代表沒有 HMI |

D107 只有數值變動時才轉到 M，所以 GX Works2 直接改 M110～M125 不會被蓋掉。

### PLC → LabVIEW

每 200 ms 分兩次讀：D200～D229、D230～D241。

| D | 內容 |
| --- | --- |
| D200、D201、D202 | 右步序、左步序、原點步序 |
| D210、D211、D212 | 右次數、左次數、總循環數 |
| D220 | 異常碼 |
| D230 | X 狀態字 |
| D231 | Y 狀態字。位元 8、9、10 是左氣缸下降、上升、左吸盤 |
| D232 | 狀態字：位元 0～5 ＝ M200～M205 |
| D241 | PLC 心跳 |
