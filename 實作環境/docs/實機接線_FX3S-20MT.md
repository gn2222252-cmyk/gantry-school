# 實機接線：FX3S-20MT/ES＋FX3G-2EYT-BD

模擬器按 **手動操作、器材與接線** 可以看同樣內容，還有端子圖和即時 X/Y 狀態。

這份依架構書、照片和三菱手冊 JY997D48601 整理，**還沒有在實機驗證**。擴充板是依架構書的 M8116、M8117 標示假定，尚未看到板子上的標示。

原本的 FX3U 版程式備份在 `backup_FX3U版\`。

## 兩個版本

| 版本 | 程式 | 硬體 | 動作 |
| --- | --- | --- | --- |
| 擴充板版 | `ladder\GANTRY_PLC` | FX3S-20MT/ES＋FX3G-2EYT-BD，10 輸出 | 左右龍門輪流，可各自搬運 |
| **8 輸出同步版** | `ladder\GANTRY_8Y` | FX3S-20MT/ES，8 輸出，不裝擴充板 | 左右氣缸、吸盤一起動作 |

模擬器跑同步版：

```bash
python softplc\softplc.py --no-board
```

同步版的輸出：Y0、Y1 左橫軸；Y2 輸送帶；Y3、Y4 左右氣缸並聯；Y5 左右吸盤並聯；Y6、Y7 右橫軸。

- 任一端有料就開始，另一邊空跑一趟，有料的一邊才計數。
- 橫軸各自碰感測器停；Y4 下降要兩邊都在定位，橫軸移動要兩邊氣缸都在上限。
- 左右都報異常碼 10、11，沒有 20、21。
- Main.vi 的左步序顯示右步序＋20。
- Y3、Y4、Y5 都帶兩顆線圈，Y4、Y5 同在 COM4，合計要在 0.8 A 以下。

## 和架構書的差異（擴充板版）

| 項目 | 架構書 | 現在 |
| --- | --- | --- |
| 模式開關 | X16 | X10 |
| 啟動、停止、復歸 | X14、X15、X17 | 沒有輸入點，由 LabVIEW 寫 M100、M101、M103 |
| 左氣缸下降、上升 | Y10、Y11 | M8116、M8117（BY0、BY1） |
| 左吸盤 | Y12 | 和右吸盤一起接 Y5 |
| 指示燈、蜂鳴器 | Y13、Y14、Y15 | 沒有輸出點，狀態看 LabVIEW |
| 輸出型式 | 繼電器，COM 接 24V | 電晶體漏型，COM 接 0V |

## 吸盤共用

機構要 11 個輸出，這台只有 10 個，所以左右電磁閥並聯在 Y5。

- 程式讓兩邊不會同時吸取或搬運：一邊在 S21～S26 或 S41～S46 時，另一邊在等料步等待。同時到時右龍門優先。
- Y5 ON 時另一顆吸盤會空吸，只是多耗氣。
- 手動按左或右吸盤，兩邊都會動作。

如果現場左吸盤接在別的地方，改 P9 的 Y5 和 S20、S40 的條件即可。

## 手動與 GX Works2

手動邏輯在 PLC 的 P7 段，LabVIEW 寫 D106、D107，PLC 再轉成 M100～M125，所以 GX Works2 直接改這些 M 也能操作。

| 動作 | 軟元件 | 動作 | 軟元件 |
| --- | --- | --- | --- |
| 左往前 | M110 | 右往前 | M120 |
| 左往後 | M111 | 右往後 | M121 |
| 左下降 | M112 | 右下降 | M122 |
| 左上升 | M113 | 右上升 | M123 |
| 吸盤 | M114 或 M124 | 輸送帶 | M125 |
| 自動啟動 | M100 | 循環停止 | M101 |
| 原點復歸 | M102 | 異常復歸 | M103 |

1. 關閉 LabVIEW，X10 切手動，PLC 在 RUN。
2. 開監看，用 Debug → Modify Value 把 M 寫成 ON。
3. M110～M125 要停時再寫成 OFF，不會自己放開。M100～M104 程式會自己清除。
4. 回自動前要重新原點。

不要直接改 Y：程式每次掃描都會蓋掉，也會繞過互鎖。

## 端子（FX3S-20MT/ES，AC 電源）

```text
輸入側上排   ⏚   S/S  X1  X3  X5  X7  X11 X13
輸入側下排 L   N   X0  X2  X4  X6  X10 X12

輸出側上排   0V  Y0   Y1   Y2   Y3   Y4   Y6  ．
輸出側下排 24V COM0 COM1 COM2 COM3 COM4 Y5  Y7
```

`．` 是空端子，不可接線。擴充板端子是 BY0+、BY0-、BY1+、BY1-。

## 輸入

S/S 接 PLC 的 24V，是漏型接法。PLC 服務電源最多 400 mA，不要把外部電源接到 PLC 的 24V 端子。

| 位址 | 裝置 | 接法 |
| --- | --- | --- |
| X0、X2、X4、X5 | 光電 NPN 3 線 | 棕→24V，藍→0V，黑→X |
| X1、X3 | 近接 NPN 3 線 | 棕→24V，藍→0V，黑→X |
| X6、X7、X11、X12 | 磁簧 2 線 | 棕→X，藍→0V |
| X10 | 選擇開關 | X→開關→0V，ON 自動 |
| X13 | 急停第 1 組 NC | X→接點→0V，平常要亮 |

## 輸出

- 所有 COM 接外部電源的 0V，負載一端接 +24V，另一端接 Y。
- 只能用 DC 5～30V。每點最大 0.5 A，COM4（Y4～Y7）合計 0.8 A 以下；Y5 接兩顆線圈，電流要相加。
- 輸出內部沒有保險絲，每路負載要自己加。
- 12V 馬達不能直接接 Y，要經過繼電器。
- 線圈沒有內建保護時，並聯續流二極體，陰極朝 +24V。
- 右馬達的繼電器模組要選低電位觸發，因為 Y 導通時是拉到 0V。

| 位址 | 接到 | 共點 |
| --- | --- | --- |
| Y0、Y1 | 中間繼電器 → 左馬達 | COM0、COM1 |
| Y2 | 中間繼電器 → 輸送帶馬達 | COM2 |
| Y3 | 右 4V220 B 側線圈 | COM3 |
| Y4 | 右 4V220 A 側線圈 | COM4 |
| Y5 | 左右 3V110 線圈並聯 | COM4 |
| Y6、Y7 | 繼電器模組 → 右馬達 | COM4 |
| BY0（M8116） | 左 4V220 A 側線圈 | 看 2EYT-BD 手冊 |
| BY1（M8117） | 左 4V220 B 側線圈 | 看 2EYT-BD 手冊 |

## 硬體保護

- 急停第 2 組 NC 串在負載的 +24V，不是串在 COM。
- LS1～LS4 常閉，串在馬達迴路。
- 馬達正反轉繼電器做硬體互鎖。

## 上實機前要確認

| 項目 | 狀態 |
| --- | --- |
| 軟元件範圍 | 已對照手冊，都在範圍內 |
| S、D 斷電保持 | 已修：開機清除，並有測試 |
| `LD=`、`AND=` 等指令 | 要用 GX Works2 編譯確認 |
| FX3S 版本支援 2EYT-BD | 手冊寫 Ver. 1.20 起支援相關擴充板，要查機身版本 |
| D200～D253 的 EEPROM 保持 | 手冊未說明高頻寫入的影響，要查 |
| LabVIEW 實機通訊 | 已改成編程協定走內建 RS-422，見 `docs\通訊協定.md`。沒有接過真的 PLC，位址格式要實機確認 |
