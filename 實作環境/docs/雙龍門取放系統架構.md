## 1. 系統概述

### 1.1 機構

```
            左龍門                                   右龍門
         ┌──────────┐                            ┌──────────┐
 後輸送帶 │  ← ← ← ← ← ← ← ← ← ← ← ← ← ← ← ← ← ← ← │  (右→左)
         │                                          │
 前輸送帶 │  → → → → → → → → → → → → → → → → → → → │  (左→右)
         └──────────┘                            └──────────┘
```

- 兩條輸送帶平行、方向相反，由同一個輸出 Y2 同時驅動。
- 兩座龍門各跨在輸送帶的一端，各有：
  - 一支**橫軸**：直流馬達＋螺桿，在「前側（前輸送帶上方）」與「後側（後輸送帶上方）」之間移動
  - 一支**升降氣缸**：雙動電磁閥控制，氣缸上有上限、下限磁簧開關
  - 一個**真空吸盤**：單動常閉電磁閥控制
- 橫軸兩端各有一個極限開關（LS1～LS4），以**常閉接點串在馬達迴路**做硬體超程保護，不進 PLC。

### 1.2 動作（循環搬運）

1. 物件在**前輸送帶**由左往右送到右端，被到位感測器偵測。
2. **右龍門**在前側吸起物件，移到後側放到**後輸送帶**。
3. 後輸送帶把物件由右往左送到左端，被到位感測器偵測。
4. **左龍門**在後側吸起物件，移到前側放回**前輸送帶**。
5. 回到第 1 步，無限循環，直到按停止。

## 4. 動作規格

### 4.1 模式

| 模式 | 條件 | 說明 |
|---|---|---|
| 手動 | X16 OFF | 只能由 LabVIEW 的手動頁點動各元件，互鎖仍有效 |
| 自動 | X16 ON | 按啟動（現場或 LabVIEW）開始循環 |
| 原點復歸 | 開機、急停解除後、或手動按復歸 | 自動運轉前必須完成 |

### 4.2 原點定義

| 項目 | 原點狀態 |
|---|---|
| 左龍門 | 在後側（X1 ON）、氣缸上（X6 ON）、吸盤 OFF |
| 右龍門 | 在前側（X2 ON）、氣缸上（X11 ON）、吸盤 OFF |
| 輸送帶 | 停止 |

原點位置就是各自的取料位置，龍門平時停在那裡等料。

### 4.3 原點復歸流程

1. 全部輸出 OFF，吸盤 OFF。
2. 左右氣缸上升（Y11、Y3），直到 X6、X11 ON。
3. 左龍門往後（Y1）直到 X1 ON；右龍門往前（Y7）直到 X2 ON。兩邊同時進行。
4. 完成後原點完成旗標 M20 ON，綠燈常亮。

每一步逾時 5 秒（D102）即報警。

### 4.4 右龍門自動流程（前 → 後）

| 步 | 狀態 | 動作 | 轉移條件 |
|---|---|---|---|
| S20 | 等料 | 無 | X4 ON 且 X2 ON 且 X11 ON 且 非循環停止 |
| S21 | 下降 | Y4 | X12 ON |
| S22 | 吸附 | SET Y5，計時 D100 | 計時到 |
| S23 | 上升 | Y3 | X11 ON |
| S24 | 往後 | Y6 | X3 ON |
| S25 | 下降 | Y4 | X12 ON |
| S26 | 釋放 | RST Y5，計時 D101 | 計時到 |
| S27 | 上升 | Y3 | X11 ON |
| S28 | 往前回原點 | Y7 | X2 ON → 計數＋1，回 S20 |

### 4.5 左龍門自動流程（後 → 前）

| 步 | 狀態 | 動作 | 轉移條件 |
|---|---|---|---|
| S40 | 等料 | 無 | X5 ON 且 X1 ON 且 X6 ON 且 非循環停止 |
| S41 | 下降 | Y10 | X7 ON |
| S42 | 吸附 | SET Y12，計時 D100 | 計時到 |
| S43 | 上升 | Y11 | X6 ON |
| S44 | 往前 | Y0 | X0 ON |
| S45 | 下降 | Y10 | X7 ON |
| S46 | 釋放 | RST Y12，計時 D101 | 計時到 |
| S47 | 上升 | Y11 | X6 ON |
| S48 | 往後回原點 | Y1 | X1 ON → 計數＋1，回 S40 |

### 4.6 輸送帶規則

自動運轉中 Y2 ON，以下任一成立時暫停：

- X4 ON（前輸送帶有料等右龍門取）
- X5 ON（後輸送帶有料等左龍門取）
- 任一龍門在下降、吸附、釋放、上升步（S21～S23、S25～S27、S41～S43、S45～S47）

物件被吸起後感測器 OFF，龍門回到上方，輸送帶自動恢復。

### 4.7 停止、急停與異常

| 事件 | 處理 |
|---|---|
| 按停止（X15 或 HMI）| 設循環停止旗標，兩座龍門完成目前這一趟並回原點後停止，紅燈亮 |
| 急停（X13 OFF）| 立即清除所有步序與輸出，紅燈閃、蜂鳴器響；解除後需按復歸並重新原點復歸 |
| 動作逾時 | 任一步停留超過 D102 設定時間：停止該龍門與輸送帶、寫入異常碼、紅燈閃、蜂鳴器響 |
| 異常復歸 | 按復歸（X17 或 HMI），清除異常，需重新原點復歸 |

### 4.8 互鎖（程式中一律檢查）

1. 馬達正反轉互鎖：Y0/Y1 不可同時 ON；Y6/Y7 不可同時 ON。硬體上 R1～R3 也互鎖。
2. 氣缸上升／下降互鎖：Y3/Y4 不可同時 ON；Y10/Y11 不可同時 ON。
3. 橫軸移動前，該龍門氣缸必須在上限（X6 或 X11 ON）。
4. 氣缸下降前，龍門必須在前側或後側定位點上。
5. 急停中或異常中，所有輸出 OFF。
6. 手動模式下，HMI 點動也套用以上互鎖。

## 5. PLC 程式架構

### 5.1 程式段落

| 段落 | 內容 |
|---|---|
| P1 初始化 | M8002：SET S0、載入預設參數（D100～D103 若為 0 則寫入預設值）|

| P8 逾時監視 | 每座龍門一個逾時計時器，步序改變時重設 |

| M8013 | 1 秒脈衝（PLC 心跳）|

## 6. 上位機能不能直接控制 PLC？

**可以。** LabVIEW 透過通訊可以即時讀寫 PLC 的 X、Y、M、D 等軟元件。但要注意：

- PLC 的程式每次掃描都會重新計算 Y。LabVIEW **直接寫 Y**，下一次掃描就會被程式覆蓋，而且會繞過互鎖，**不建議**。
- 正確做法：**LabVIEW 寫 M 命令位元或 D 參數，PLC 程式讀到後再去驅動 Y**。這樣互鎖、急停仍由 PLC 負責，上位機當機或斷線也不會讓機台失控。

所以上位機可以做到：

| 功能 | 方式 |
|---|---|
| 遠端啟動、停止、原點復歸、異常復歸 | 寫 M100～M103（脈衝）|
| 手動點動每個馬達、氣缸、吸盤、輸送帶 | 寫 M110～M131（按住為 ON，放開為 OFF）|
| 修改吸附時間、逾時、目標次數 | 寫 D100～D103 |
| 即時監視所有 I/O、步序、計數、異常 | 讀 D200～D241、M200～M249 |
| 歷史紀錄 | LabVIEW 端寫 CSV |

### 7.3 計算機連結封包（格式 1）

**命令（電腦 → PLC）**

```
ENQ | 站號(2) | PC號(2) | 指令(2) | 等待(1) | 內容 | 和校驗(2)
05H | "00"    | "FF"    | "BR"    | "0"     | ...  | "XX"
```

- 和校驗：從站號到內容最後一個字元的 ASCII 值加總，取低位元組，轉成 2 個 ASCII 十六進位字元。
- 軟元件寫法：位元件 5 字元（`X0000`、`M0100`），字元件 5 字元（`D0200`）。

**常用指令**

| 指令 | 功能 | 內容範例 | 說明 |
|---|---|---|---|
| BR | 讀位元 | `X0000` `10` | 從 X0 起讀 16 點 |
| WR | 讀字 | `D0200` `10` | 從 D200 起讀 16 字 |
| BW | 寫位元 | `M0100` `01` `1` | M100 寫 ON |
| WW | 寫字 | `D0100` `01` `0005` | D100 寫 5 |

**回應（PLC → 電腦）**

- 讀取成功：`STX | 站號 | PC號 | 資料 | ETX | 和校驗`
- 寫入成功：`ACK | 站號 | PC號`
- 錯誤：`NAK | 站號 | PC號 | 錯誤碼(2)`

> 封包細節請以三菱《FX 系列使用者手冊 通訊篇》計算機連結章節核對。

## 8. 測試項目

| # | 項目 | 預期 |
|---|---|---|
| 1 | 開機 | S0 待機，紅燈亮，未原點 |
| 2 | 原點復歸 | 兩座龍門回原點，氣缸上，綠燈亮 |
| 3 | 自動單趟 | 放一個物件，完整繞一圈，計數各＋1 |
| 4 | 多物件 | 放 2～3 個物件，輸送帶正確暫停與恢復 |

| 7 | 逾時 | 拔掉一顆感測器線，應在 5 秒內報對應異常碼 |
| 8 | 互鎖 | 手動模式下，氣缸在下方時按橫軸點動應無動作 |

| 11 | 通訊中斷 | 拔掉 485 線，HMI 顯示斷線；手動點動中的輸出自動停止 |

## 9. 開發順序

1. 依第 3 節產生**軟元件註解 CSV**。
2. 寫 PLC 程式 P1～P10，先完成手動與原點復歸，再寫自動流程。
3. 寫 **Python PLC 模擬器**：
   - 監聽虛擬 COM 埠（或 TCP），實作 BR/WR/BW/WW
   - 內部用字典存 X/Y/M/D
   - 簡單模擬機構（例如 Y6 ON 兩秒後 X3 ON）
4. 依第 7 節寫 LabVIEW 各 VI 的說明與方塊圖步驟，先用模擬器測通訊。
5. 上實機：先手動逐點測 I/O，再原點復歸，再自動單趟、多物件。
6. 依第 8 節逐項測試並記錄。
